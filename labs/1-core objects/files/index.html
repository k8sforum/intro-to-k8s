Agenda

What we cover

01

Cluster basics

What Kubernetes solves (availability, scalability), control plane vs worker nodes, inspecting clusters and contexts, creating a k3d cluster

02

Namespaces

Listing, creating and switching the default namespace for kubectl

03

Workloads

Pods (CLI and manifest), Deployments (scaling and self-healing), using describe

04

Labels

Viewing, selecting (-l) and adding labels to resources

05

Networking

Port forwarding, Services (ClusterIP, LoadBalancer) and Endpoints, Ingress with a local hostname (k8s.local)

06

Configurations

ConfigMaps (mounted as a volume and injected as environment variables)

07

Storage

StorageClass, PersistentVolume and PersistentVolumeClaim, dynamic (local-path) vs static (manual) provisioning, data surviving pod deletion, and the Delete vs Retain reclaim policies

08

Cleanup

Deleting the cluster, reclaiming Docker disk space and removing the k8s.local host entry
